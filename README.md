# SysMD Notebook 

(c) TU Kaiserslautern, Chair of Cyber-Physical Systems

This repository contains the AGILA SysMD Notebook.
It implements the SysMD language, a subset of SysMLv2 textual, and a constraint solver that checks the consistency of SysMD models.
The language permits the description of models in a subset of the SysMLv2/KerML metamodel. 


## Running SysMD Notebook
To run the frontend, just use the build system Gradle: 


```
./gradlew run
```
