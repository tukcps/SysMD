# Examples

This project contains a collection of examples: 

- Example-Amplifier shows the application in electrical engineering. 
  Note that SystemC model skeletons and test benches can be generated and the 
  results of the test benches can be re-read into SysMD (not part of this example).
- Modeling of automotive systems (disabled in this version; needs an update)
